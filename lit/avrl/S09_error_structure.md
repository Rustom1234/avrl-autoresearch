# S09: Structure of Model and Judge Errors Across Prompt Space

## 1. Contribution to the thesis (three sentences)

This angle supplies the mechanistic assumption the AVRL allocator depends on: that proxy-reward and judge errors are not uniform noise but cluster predictably in prompt/embedding space, so a learned policy can in principle anticipate where the cheap proxy will fail before paying for the expensive verifier. Slice-discovery and dataset-difficulty work (Domino, GEORGE, Dataset Cartography, V-usable information) establishes the general finding that model errors concentrate in identifiable, embeddable subpopulations rather than scattering randomly, which is the same structural premise applied one layer up to judges and reward models. Evaluation-diagnosis work on LLMs specifically (ProbeLLM, FailureScope, LLM-as-judge bias surveys) shows this clustering holds for judges too, but treats it as a static, post-hoc auditing problem rather than something exploited online during RL training, which is exactly the gap AVRL's in-training allocator targets.

## 3. Support versus threat to the thesis claim

Supports the claim: Domino, GEORGE, Dataset Cartography, and V-usable information together give a well-replicated, decade-spanning result that model and annotation errors are not IID across input space, they concentrate in discoverable, embeddable slices (source 1, 2, 3, 4). ProbeLLM and FailureScope extend this specifically to LLM failure and judge failure in 2026, and FailureScope's 73-100 point ASR gap (source 7) is a concrete, large, structured judge-error effect tied to an identifiable evaluation regime, exactly the kind of exploitable structure AVRL's allocator needs to exist. Gao, Schulman, and Hilton (source 5) show proxy-reward divergence from gold reward is itself a smooth, predictable function of optimization pressure, meaning at least one axis of proxy error is learnable in principle, not adversarial noise.

Threatens the claim: every source above that demonstrates structure does so post-hoc and offline (source 1, 2, 3, 4, 6, 7), none trains an online policy that exploits the structure while the base policy is simultaneously shifting under RL updates, so whether a learned allocator can track a moving target (the policy's own error distribution changing under training) is UNVERIFIED by this literature. The judge-bias surveys (source 8-12) mostly characterize biases as global properties of the judge model (verbosity, position, self-enhancement) rather than prompt-cluster-local properties, which weakens the specific premise that errors cluster in prompt-embedding space rather than being a constant additive bias the allocator cannot exploit differentially. Scaling-laws work (source 5) is about reward-model overoptimization broadly, not about whether a cheap proxy's error is predictable from features available before the expensive call is made, which is the harder, more specific claim AVRL needs and which no source here directly measures.

## 4. Closest prior work from this angle

The single closest prior work is ProbeLLM (Huang et al., 2026, https://doi.org/10.48550/arxiv.2602.12966). It directly targets the same object, structured, prompt-space failure patterns in LLM behavior, using an automated, exploration-exploitation-flavored search (hierarchical MCTS) to move from isolated failure cases to consolidated, interpretable weakness categories, which is conceptually close to a policy that must decide where to spend diagnostic effort. It differs from AVRL in three ways: it operates at evaluation time on a fixed, already-trained model rather than inside an RL training loop where both the policy and the exploitable error structure are non-stationary; it diagnoses model failures directly rather than proxy-reward or judge errors specifically, so it never addresses the verification-cost tradeoff; and it produces a human-readable taxonomy as its output rather than a budget-capped action (call the expensive verifier or not) that feeds back into a reward signal. AVRL's contribution, relative to ProbeLLM, is closing that loop: using the same kind of discovered prompt-space structure not just to report where a model or judge is weak, but to actively decide, per rollout group and under a hard budget, whether to trust the proxy or pay for ground truth, while the policy being evaluated is itself still learning.
