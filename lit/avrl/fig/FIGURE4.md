## Reading

Every trained arm beats the untrained base model on its held-out metric, in all five panels. No allocation rule, whether label-free threshold, learned allocator, or reference, separates from the others on held-out quality; within each panel the arms cluster together, well inside the gap from the untrained base.

Footnote: Common re-evaluation of final adapters: fixed held-out subsets (eval seed 0), 320-token responses and one 4-bit 3B judge for the open-ended panels, full MBPP test set for code. Each marker is one seed; the bar is the seed mean.
