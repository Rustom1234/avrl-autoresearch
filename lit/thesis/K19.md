# K19: Adversarial prior-art hunt on H19 (unlearning verification)

## Three closest 2025-2026 works

1. **PreUnlearn: Auditing Collateral Knowledge Damage Before Large Language Model Unlearning**, 2026. https://arxiv.org/abs/2606.18473
   Finds "collateral damage is strongest near the forget set, weakens with semantic distance," but persists across domain boundaries, and shows interaction features between forget set and eval set are the strongest predictive signal, computed before any unlearning run. This is a cheap, non-learned, pre-attack predictor of exactly the spatial/semantic clustering H19 Phase 1 sets out to test empirically. UNVERIFIED: exact correlation numbers, only summarized abstract seen, not full PDF.

2. **Measure, Don't Optimize: Forecasting Recovery in LLM Unlearning (J-Access)**, 2026. https://arxiv.org/abs/2608.11408
   Audited 398 public unlearned models across 8 methods. Finding: pre-attack Jacobian accessibility "predicts recovery speed and extent at the model level, but cannot identify which specific facts will be recovered," and optimizing against the audit signal teaches the model to hide knowledge rather than delete it (Goodhart failure). This is a cheap-signal attempt that explicitly fails at item-level ranking, which if anything supports H19's precondition that cheap features can't do the job alone. UNVERIFIED: exact recovery-speed correlation figures, abstract-level only.

3. **Stress Testing Unlearning Algorithms (WMDP++)**, 2026. https://arxiv.org/abs/2608.22527
   Extends WMDP with (a) active, targeted extraction of unlearned information and (b) systematic evaluation on "boundary questions," benign queries semantically close to unlearned content, i.e. the paraphrase neighborhood H19 wants a policy to route probes into. No accuracy numbers surfaced in the abstract. UNVERIFIED: quantitative results, abstract-level only.

## Strongest "already done / cannot work" argument

PreUnlearn already delivers a cheap, non-learned, pre-attack heuristic (interaction features between forget and eval sets) that predicts where collateral/residual signal concentrates by semantic distance. H19's own kill criterion #2 says: if a non-learned cluster-contagion heuristic gets within 10% of achievable budget efficiency, kill the RL/DQN framing and ship the heuristic. PreUnlearn is close to that heuristic already existing in the literature, for collateral damage rather than post-attack residual knowledge specifically, so the informed prior should shift toward "a cheap heuristic probably suffices" before spending months 5-8 training a bandit/DQN.

## Judgment

None of the three build or validate a sequential, budget-constrained probe-selection *policy* compared against uniform and heuristic baselines using actual expensive attacks (relearning, extraction) as the measurement, which is H19's specific deliverable. WMDP++ operationalizes paraphrase-neighbor probing but as a fixed benchmark, not adaptive. J-Access confirms item-level prediction from cheap signals remains open (2026, 398 models), which is genuinely load-bearing support for H19. So the precondition work is partially but not fully done: spatial clustering is suggested (PreUnlearn) but not shown for post-hoc residual knowledge specifically under adversarial probing, and cheap-signal insufficiency at item level is now directly confirmed rather than merely inferred from MIA literature.
