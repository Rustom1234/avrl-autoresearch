# K12: Adversarial prior-art kill attempt on H12 (budgeted contamination search)

## Three closest works

1. **Yang, Chiang, Zheng, Gonzalez, Stoica, "Rethinking Benchmark and Contamination for Language Models with Rephrased Samples," 2023.** https://arxiv.org/abs/2311.04850 — the LLM Decontaminator: cheap embedding prefilter, then expensive LLM verification per candidate pair. Confirmed number: found 8-18% of the HumanEval benchmark overlapping in RedPajama-Data-1T and StarCoder-Data that n-gram-only filters missed. This is a static, non-adaptive, top-K cascade, already the baseline H12 proposes to beat.

2. **"Beyond Surface-Level Similarity: Hierarchical Contamination Detection for Synthetic Training Data in Foundation Models," 2025.** https://arxiv.org/abs/2511.17602 — a four-tier cascade (token level, semantic level, reasoning-pattern level, performance-cliff level), evaluated on MMLU, GSM8K, HumanEval. Confirmed numbers: semantic-level tier reaches F1=0.76 versus F1=0.17-0.49 for existing methods, average 26.5% improvement over state-of-the-art baselines. This is structurally the closest prior work to H12: a tiered cheap-to-expensive pipeline over the same benchmark set H12 proposes to use in Phase 1. It is static/rule-ordered rather than a learned bandit, which is the one place H12 still differs.

3. **Soldaini et al., "Dolma: an Open Corpus of Three Trillion Tokens for Language Model Pretraining Research," 2024.** https://arxiv.org/abs/2402.00159 — production-scale decontamination via Bloom filter seeded with test examples, applied during corpus mixing. Confirmed number: the Dolma toolkit filters at 122 CPU-hours per TB. This is the "cheap layer is already solved at negligible cost, at full corpus scale" data point: labs are not budget-constrained on exact/near-exact decontamination today.

## Strongest reason a committee kills it

Combine (1) and (3): the cheap exact/fuzzy layer already runs on the entire corpus at ~122 CPU-hours/TB (Dolma), so there is no real budget-scarcity problem at that layer needing a bandit. And for the expensive semantic layer, a static tiered cascade (Beyond Surface-Level Similarity, 2025) already gets a 26.5% average improvement over prior baselines using the same cheap-then-expensive structure H12 proposes, without a learned policy. So the committee's line: "the industry problem (cheap layer) is already solved for free, and the research problem (expensive layer) already has a strong static cascade competitor that gets most of the gain; an adaptive bandit on top only wins if host-level contamination autocorrelation is real and strong, and that number does not exist in any paper found." This matches H12's own section 3 admission (UNVERIFIED host-level autocorrelation), which is the load-bearing and only unverified premise.

## Judgment

A year-long thesis retains a defensible gap, but it is narrower than framed: not "build an adaptive contamination search" but "measure whether host/domain autocorrelation of contamination is strong enough that any adaptive policy could ever beat the 2025 static cascade baseline at matched expensive-call budget." If that measurement comes back weak, the whole SOFisher framing collapses to a null result, which H12's own kill criteria (section 6) already anticipate.
