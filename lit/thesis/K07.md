# K07: Adversarial Prior-Art Hunt on H7 (Active Data Acquisition)

## Three closest works

1. **Yu, Zhang, et al., "Crawl4LLM," ACL Findings 2025, arXiv 2502.13347.** Static, one-shot influence-ranked crawl scheduler. On a 900M-page graph, matches full-crawl downstream performance fetching only 21% of URLs (79% reduction). https://arxiv.org/abs/2502.13347

2. **"Hubs or Fringes: Pretraining Data Selection via Web Graph Centrality" (WebGraphMix), arXiv 2606.11499, 2026.** Static, one-shot graph-centrality data selection, tested in DataComp-LM at 400M/1B params. Central+peripheral 1:1 mix gets 41.4% avg over 23 tasks vs 39.8% uniform (+1.6pp); adding a quality classifier gets 43.8%. This is the most direct existing test of H7's Condition 1 (graph autocorrelation of value): standalone, the signal is real but small; most gain is from the classifier, not position. No comparison to Crawl4LLM found. https://arxiv.org/abs/2606.11499

3. **"Neural Prioritisation for Web Crawling," arXiv 2506.16146, 2025.** Static neural semantic-quality estimator reprioritizes the crawl frontier, improving early-stage harvest rate on ClueWeb22-B/MS MARCO Web Search. Targets search relevance, not LLM pretraining; exact deltas not in abstract. UNVERIFIED magnitude. https://arxiv.org/abs/2506.16146

Found via Semantic Scholar's citation graph for Crawl4LLM (queried 2026-09-22); WebSearch was unavailable this session (budget exhausted), so recall beyond these three is UNVERIFIED.

## Strongest "already done / cannot work" argument

None of the three run a sequential, in-the-loop policy updating region choice from realized yield mid-crawl (H7's core claim); all are static one-shot scorers. WebGraphMix (2026) is the closest real test of whether graph position alone predicts pretraining value, and the answer is a small effect (+1.6pp over uniform), not the "moderate-strong" autocorrelation H7 asserts from indirect evidence (Crawl4LLM's 79% figure conflates position with a full influence model, not raw autocorrelation). If the direct signal is this thin, a sequential bandit has little headroom to beat Crawl4LLM's already-saturating one-shot score by the thesis's own >=10% kill bar.

Institutional flaw: labs source Common Crawl or negotiate licensing through legal/business teams (per H07's own deal-tracker citation), not novel crawlers at scale; a one-year thesis cannot build that infrastructure or get real licensing cost/yield data, so Phase 3 can only be simulated, never actually testing H7's licensing claim.

## Verdict

A narrow gap survives: no found work benchmarks sequential yield-updating region selection against Crawl4LLM's static score under matched scoring compute. But the autocorrelation premise (WebGraphMix) is weaker than assumed, and the licensing arm is untestable for real. Phase 1-2 (crawl) is defensible; Phase 3 (licensing) should be cut or downgraded to a toy simulation with no real-world claim.
