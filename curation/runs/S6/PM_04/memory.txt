- (dev bpb 1.8225) Replace the random whole-pool order with a filter that keeps only clean, in-domain (WikiText-style) documents, deduplicated. 1. **Exact dedupe:** lowercase and collapse whitespace, hash the text, and keep the first occurrence. Also drop any document whose first 300 normalised characters match an already kept one. 2. **Junk filter:** drop documents that - have fewer than 200 characters; - have a unique-line ratio below 0.5 (repeated boilerplate lines such as the "Click here to subscribe" document); - have a zlib compression ratio (compressed/raw) below 0.2; - have less than 80% of characters that are ASCII letters or spaces. 3. **Domain filter:** keep only documents that look like the target format: the first line matches `^= .+ =$`, or the document has at least 2 WikiText tokenisation markers (`' @-@ '`, `' @,@ '`, `' @.@ '`, `' , '`, `' . '`) per 1000 characters. 4. **Shuffled-word filter:** build a set of lowercase whitespace-word bigrams from the first 100 documents of `target_sample`. Define a document's hit rate as the fraction of its bigrams (first 2000 words) that are in the set. Compute the hit rate on the other 100 target documents and set the threshold to 0.85 × their 2nd percentile. Drop pool documents below it; this catches the word-scrambled wiki articles such as "Pulaski Skyway" and "U-37". 5. **Output:** shuffle the kept indices with `CURATE_SEED`. Count tokens with tiktoken gpt2, or estimate as characters/4 if that is too slow. If the kept set holds fewer than T tokens, append further independently reshuffled passes of the kept set until the list reaches at least T tokens. Do not pad with off-domain text.

(1) Build a word-level TF-IDF (or hashed unigram+bigram) logistic-regression classifier: positives = the 200 target_sample docs (plus their halves/chunks to get more examples), negatives = a seeded random sample of ~3000 pool docs; score every pool doc. Combine with cheap structural features of the target domain (WikiText style): doc starts with '= Title =' on line 1, presence of ' @-@ ', ' , ' and ' . ' spaced punctuation. (2) Remove damaged docs: detect word-shuffled articles (the pool contains wiki-looking docs whose words are scrambled within sentences) by scoring each doc with a bigram model fit on target_sample plus clearly-clean high-scoring docs — e.g. fraction of adjacent word bigrams in the doc that appear in the target-sample bigram set, or mean per-token bigram log-prob with add-k smoothing; shuffled docs have far lower bigram hit rate than clean ones at the same unigram similarity, so threshold at the valley of the bimodal distribution among wiki-style docs (fallback: drop the bottom mode via 2-means on the hit rate).
