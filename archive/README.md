# Archive

This folder holds material that is not part of the core project. Nothing here is needed to run or understand Part 1 (`avrl/`) or Part 2 (`loop/`).

- `active-audit/` is an earlier project in the same repository: budgeted auditing of pretraining data
  (which documents deserve an expensive sensitivity check). It is kept for the record. It holds the
  scope document (`SCOPE.md`), the data and labelling helpers (`aa/`), the simulation and measurement
  runs (`runs/`) and the literature notes written for it (`lit/`). The scripts there were run from the
  repository root before the move and still carry those paths.
- `reading-notes/` are literature notes for Part 1: one file per search angle (`S01` to `S14`), a
  synthesis, two adversarial novelty checks (`GAP_*`), the pre-registered experiment backlog, a
  literature synthesis for the research loop of Part 2, and the results figures with the scripts that draw them (`fig/`, which read `avrl/runs/`).
