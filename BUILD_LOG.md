## 2026-09-18
- Question reframed by Rustom: which directions for SOFisher-style active search are legitimately relevant to LLM training. Four Sonnet literature passes written to lit/A_online_selection.md (online/model-aware selection), lit/B_active_search.md (active search, SOFisher primary details), lit/C_corpus_structure.md (where undesirable content clusters), lit/D_expensive_scorers.md (which scorers are truly budget-bound). Synthesis and ranked directions in lit/DIRECTIONS.md.
- Verified from arXiv 2406.06046: MATES computes oracle influence on a RANDOM hold-out subset (80k then 20k per 10k-step update), data selection is 21.7% (410M) / 11.5% (1B) of total FLOPs. Adaptive probe selection is untried. This is direction D1.
- Judge crash root cause (both Sep 10 and Sep 18 relaunches): Triton compiles a driver helper at startup and needs Python.h, which is not installed on goldberg (no python3.12-dev, no sudo). enforce_eager does not avoid it. Fix: headers extracted from the Ubuntu .deb into ~/.local/include/python3.12 and CPATH exported in every GPU job script. Applies to .venv (transformers) jobs too, one such job died the same way today.
- Code secrets, 2 shards of codeparrot/github-code-clean (253,850 files, ungated, runs/code): regex neighbor ratio by repo 33x (high-confidence patterns) / 20x (generic password= patterns), cheap-feature AUC 0.80. NOT trustworthy yet: 104 high hits sit in 103 repos (one repo with 2 hits carries the ratio), 68% are Google browser API keys in front-end HTML, repos are fragmented across 880 shards (median 1 file per repo in-sample). 10-shard rerun with bootstrap CIs plus a minimal budgeted-audit simulator (runs/code/sim_code.py) queued.
- Queued on the GPU, sequential (runs/gpu_queue.sh): judge 20k -> runs/hyp (edu score, Qwen3-4B loss, regex on a 73k domain-stratified sample; neighbor ratio, ICC, cheap-feature AUC per label) -> runs/infl (first-order influence grad_i . grad_ref under Qwen3-0.6B-Base, 16k docs / 800 domains, general and edu reference sets; tests whether influence has the domain structure an adaptive prober needs).
- bd (beads) is not on PATH on goldberg, so no bead issues this session; this log is the record.
- Results (Sep 18, details in lit/DIRECTIONS.md R1 to R5): the regex proxy was the wrong label (2.4% precision, 23% recall vs the Qwen3-4B judge). Judge label (0.74%, 540 positives on the 73k stratified sample) clusters by domain 6.45x and host 8.09x on real multi-doc groups (63% of hits in multi-hit domains), clearing the LOOP.md 3x gate; edu_high 1.86x, loss top decile 1.64x, regex 1.80x do not. Cheap-feature AUC for the judge label 0.65, cheap + MiniLM PCs 0.87.
- Budgeted-audit sim on the judge label over 300 embedding cells (runs/sim_generic.py): self-training Thompson bandit (no free labels) 91 / 231 hits at 3% / 10% budget vs budget-matched distill-then-scan 42 / 127, uniform 11 / 35, oracle 398. First positive result for adaptivity in this project. Static with 13.7k free labels: 111 / 214. Needs an active-learning (uncertainty sampling) baseline, more seeds, and judge validation before it is a claim.
- Code secrets (10 shards): repo lift 7 to 31x but only 10% of hits have an in-sample repo neighbour; extension AUC 0.8; static triage beats adaptive 8x vs 5x. Not testable on file-sampled shards.
- Judge throughput 7.8 docs/s with vLLM on the 5090 (both eager and compiled), 73k docs took 2.6 h. Pandas 3 groupby-apply drops the grouping column: bit score_sample.py and influence_by_domain.py; use sample(frac=1).groupby().head(n).
- Ablation (8 seeds): greedy self-training with no layout matches or beats the online bandit (cells, cheap+emb: 40/107/220 vs 16/91/230 at 1/3/10%). The 2x gain over budget-matched distill-then-scan is sequential self-training, not SOFisher's spatial structure. Influence test (runs/infl): first-order influence ICC by domain 0.14, R2 from all features 0.01, so D1 (adaptive probing for MATES) is negative. Final ranking in lit/DIRECTIONS.md: (1) budgeted sensitivity auditing by sequential self-training, (2) measurement paper, (3) code secrets needs whole repos, (4) D1 dropped.
